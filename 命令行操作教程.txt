============================================================
 从零学会：用命令行跑 NIST SP 800-22 测试（傻瓜对照版）
 本教程教你：怎么开命令行窗口、敲什么、看到什么算成功
============================================================

【第 0 课】命令行是什么
  平时用鼠标点图标操作电脑；命令行是"打字指挥电脑"的窗口。
  你要用的叫 PowerShell，是一个蓝色窗口。
  窗口里每行开头是：PS C:\Users\Christm>
  这个 > 前面写的 = 你当前所在的文件夹位置。

【第 1 课】怎么打开 PowerShell
  1. 点屏幕左下角的"开始"（Windows 图标）
  2. 直接打字：powershell
  3. 看到"Windows PowerShell"，回车（或点它）
  4. 弹出一个蓝色窗口 = 成功

【第 2 课】三个必会操作
  1. 进入文件夹：cd 路径      （cd = change directory 换目录）
       例：cd F:\fpga_project
       敲完回车，提示符会变成 PS F:\fpga_project>   = 成功
  2. 粘贴命令：在窗口里点【鼠标右键】就是粘贴（老版本），
     或 Ctrl+V（新版）。粘贴完按回车执行。
  3. 命令执行完会回到提示符 PS ...> ，说明这一步完成了。

【第 3 课】完整流程（照着敲，别敲 # 后面的话）
  第一步 进入工程目录：
     cd F:\fpga_project

  第二步 确认文件在不在（可跳过）：
     dir
     应该能看到 trng_data.bin 等文件

  第三步 跑测试（现在就能跑，用的是已有的 1MB 数据）：
     powershell -ExecutionPolicy Bypass -File F:\fpga_project\run_nist_sp80022.ps1 -DataFile F:\fpga_project\trng_data.bin -Streams 8
     屏幕会滚英文菜单（那是测试程序在问你 6 个问题，脚本帮你答好了）
     最后出现：==== DONE. Report saved to: ... = 成功！
     大约等 1 分钟。

  第四步 看结果：
     notepad F:\fpga_project\NIST_SP800-22_结果.txt
     或者直接去文件夹双击打开这个文件。
     主要看 PROPORTION 列：8/8、7/8 都是通过（最低 7/8）。

【第 4 课】正式版（报告要 100 组 = 12.5MB 数据）
  前提：FPGA 板子用串口连电脑、上电、下载好 bitstream。
  1. 采数据（大约 20~25 分钟，会显示进度百分比）：
       python capture_trng_uart.py --mode frame --frames 97657 --out trng_data_12m.bin
  2. 检查数据够不够（输出应 >= 100）：
       (Get-Item trng_data_12m.bin).Length * 8 / 1000000
  3. 跑 100 组测试：
       powershell -ExecutionPolicy Bypass -File F:\fpga_project\run_nist_sp80022.ps1 -DataFile F:\fpga_project\trng_data_12m.bin -Streams 100
  4. 看结果：这次 PROPORTION 列每行要 >= 96/100，P-VALUE 列有具体数字。

【常见问题】
  · 提示"不是内部或外部命令" = 命令敲错了，重新敲正确的
  · 粘贴进去乱掉 = 按回车清空当前行，重新粘贴
  · 窗口关了 = 重开，cd 要重新敲一遍
  · 报"数据不足" = 文件太小或组数太多，换数据或减小 Streams

【测试工具的原理（懂了这个就懂了全部）】
  assess.exe 是个一问一答的程序，英文菜单是在问你：
   数据源？(0=文件) -> 文件名？ -> 测哪些？(1=全部15项)
   -> 参数？(0=默认) -> 分几组？(100) -> 格式？(1=二进制)
  脚本 run_nist_sp80022.ps1 = 把 6 个答案一次填好喂给它。
