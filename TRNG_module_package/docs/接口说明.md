# TRNG 接口说明

## 1. 模块定位

本模块负责在 FPGA 内产生随机数，并可将 128 字节随机数送入 SHA-256，得到 256 bit 密钥材料。它面向两个队友：

- PUF 队友：使用随机字节作为 challenge、nonce 或测试随机源。
- AES 队友：使用 SHA-256 输出作为 AES 密钥。

## 2. 推荐集成模块

推荐集成文件：

```text
rtl/trng_key_provider.v
```

依赖文件：

```text
rtl/neoTRNG.vhd
rtl/trng_core.vhd
rtl/sha256.v
```

如果只做串口测试，还需要：

```text
rtl/uart_tx.v
rtl/trng_uart_top.v
constraints/trng.xdc
```

## 3. `trng_key_provider` 端口

```verilog
module trng_key_provider (
    input          clk_i,
    input          rstn_i,
    input          enable_i,

    output         trng_valid_o,
    output [7:0]   trng_data_o,

    output reg         key_valid_o,
    input              key_ready_i,
    output reg [255:0] key_data_o,
    output reg [15:0]  key_index_o,
    output             busy_o
);
```

## 4. 系统信号

| 信号 | 方向 | 位宽 | 说明 |
|---|---:|---:|---|
| `clk_i` | 输入 | 1 | 系统时钟，当前工程按 100 MHz 使用 |
| `rstn_i` | 输入 | 1 | 低有效复位 |
| `enable_i` | 输入 | 1 | TRNG 使能，1 表示允许采集随机数 |
| `busy_o` | 输出 | 1 | 1 表示正在收集随机数、计算 SHA 或等待 AES 取走密钥 |

## 5. PUF 随机字节接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---:|---:|---|
| `trng_valid_o` | 输出 | 1 | 本拍 `trng_data_o` 有效 |
| `trng_data_o` | 输出 | 8 | 随机字节 |

使用约定：

- 当 `trng_valid_o = 1` 时，PUF 队友可以在同一个时钟沿采样 `trng_data_o`。
- 当前接口没有 `ready` 背压，PUF 如果暂时不用，可以直接忽略该字节。
- 若后续 PUF 需要定长读取，例如一次读取 32 字节，可由 PUF 侧自己计数。

## 6. AES 密钥接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---:|---:|---|
| `key_valid_o` | 输出 | 1 | 1 表示 `key_data_o` 已稳定，可以作为密钥 |
| `key_ready_i` | 输入 | 1 | AES 侧取走密钥时拉高 1 拍 |
| `key_data_o` | 输出 | 256 | SHA-256 输出，可直接作为 AES-256 密钥 |
| `key_index_o` | 输出 | 16 | 密钥序号，每成功取走一把密钥加 1 |

密钥生成方式：

```text
128 字节 TRNG 原始随机数 -> SHA-256 -> 32 字节 key_data_o
```

握手时序：

```text
1. TRNG 收集 128 字节随机数。
2. TRNG 送入 SHA-256。
3. SHA-256 输出完成后，key_valid_o 拉高。
4. AES 看到 key_valid_o=1 后读取 key_data_o。
5. AES 将 key_ready_i 拉高 1 拍，表示已经取走。
6. TRNG 撤销 key_valid_o，开始生成下一把密钥。
```

字节顺序：

```text
key_data_o[255:248] = SHA-256 第 0 字节
key_data_o[247:240] = SHA-256 第 1 字节
...
key_data_o[7:0]     = SHA-256 第 31 字节
```

AES-256：

```text
直接使用 key_data_o[255:0]
```

AES-128：

```text
建议使用 key_data_o[255:128]，也就是 SHA-256 的前 16 字节
```

## 7. UART 调试帧接口

`trng_uart_top.v` 的串口输出用于测试和采样，帧格式如下：

| 字段 | 长度 | 固定值或含义 |
|---|---:|---|
| 帧头 | 2 字节 | `AA 55` |
| 长度 | 2 字节 | `00 80`，表示 128 字节 |
| 原始随机数 | 128 字节 | TRNG 输出 |
| SHA-256 | 32 字节 | FPGA 对 128 字节原始随机数计算出的 SHA-256 |
| 包尾 | 4 字节 | `5A A5 33 CC` |

说明：

- 包尾只用于判断一帧是否结束，不是 CRC。
- Python 会重新计算 `SHA256(raw_data)`，并与 FPGA 发送的 SHA-256 比较。
- 包尾错误或 SHA 不匹配的帧应丢弃，不交给 AES 使用。
