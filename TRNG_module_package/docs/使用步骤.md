# 使用步骤

## 1. 给队友的文件

把整个 `TRNG_module_package` 目录发给队友即可。

AES/PUF 板内集成至少需要加入 Vivado 的文件：

```text
rtl/neoTRNG.vhd
rtl/trng_core.vhd
rtl/sha256.v
rtl/trng_key_provider.v
```

如果队友也要跑串口测试，再加入：

```text
rtl/uart_tx.v
rtl/trng_uart_top.v
constraints/trng.xdc
software/capture_trng_uart.py
```

## 2. Vivado 添加文件顺序

建议顺序：

```text
1. neoTRNG.vhd
2. trng_core.vhd
3. sha256.v
4. trng_key_provider.v
5. uart_tx.v
6. trng_uart_top.v
```

其中 `neoTRNG.vhd` 和 `trng_core.vhd` 建议设置为 VHDL 2008。

## 3. 板内集成推荐顶层

如果队友要把 TRNG 接到 AES/PUF，不建议用 `trng_uart_top.v` 做最终顶层。推荐在他们自己的顶层里实例化：

```verilog
trng_key_provider u_trng_key_provider (
    .clk_i(clk),
    .rstn_i(rstn),
    .enable_i(1'b1),
    .trng_valid_o(trng_valid),
    .trng_data_o(trng_data),
    .key_valid_o(key_valid),
    .key_ready_i(key_ready),
    .key_data_o(key_data),
    .key_index_o(key_index),
    .busy_o(trng_busy)
);
```

## 4. 串口测试步骤

1. 使用 `trng_uart_top.v` 作为顶层。
2. 综合、实现、生成 bitstream。
3. 下载 bitstream 到开发板。
4. 运行：

```powershell
python F:\fpga_project\TRNG_module_package\software\capture_trng_uart.py --port COM9 --mode frame
```

如果串口不是 COM9，把 `--port COM9` 改成自己的串口号。

## 5. 错误处理规则

采集脚本会检查：

```text
帧头 AA55
长度 0080
包尾 5AA533CC
SHA256(raw_data) 是否等于 FPGA 发来的 SHA256
```

处理规则：

```text
包尾错误：丢弃该帧，重新找帧头
SHA 不匹配：丢弃该帧，记录到日志
全部通过：保存 raw_data 到 trng_data.bin
```

## 6. 对接口前必须确认的问题

AES 队友：

```text
1. 用 AES-128 还是 AES-256？
2. 是每次加密换一把密钥，还是启动时取一把？
3. 是否需要 key_index_o 做调试？
```

PUF 队友：

```text
1. 每次需要多少 bit 随机 challenge？
2. 是否能接受无 ready 的随机字节流？
3. 是否需要固定长度 valid 信号？
```

三方共同：

```text
1. 是否统一使用 100 MHz 时钟？
2. 复位是否统一为低有效 rstn？
3. 是否所有模块都在同一块 FPGA 内部连接？
```
