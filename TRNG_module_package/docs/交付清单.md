## 当前版本接口摘要

### 板内密钥接口

```text
key_valid_o
key_ready_i
key_data_o[255:0]
key_index_o[15:0]
```

### 板内随机字节接口

```text
trng_valid_o
trng_data_o[7:0]
```

### UART 调试帧

```text
AA 55 + 00 80 + 128B raw + 32B SHA256 + 5A A5 33 CC
```

## 交付说明

本交付包面向当前 SRTP 阶段对接使用。若后续 AES/PUF 队友确认需要 `ready` 背压、FIFO、AXI-Stream 或 AXI-Lite 寄存器接口，需要在下一版接口中增加。
